# GlowAI AI regression check — 27 September 2026

## What changed
- Face proportions now compare forehead landmarks 54/284 with cheek width, instead of the near-duplicate cheek-level 127/356 measurement. Prototype ratios now refer to the measured MediaPipe face mesh rather than full-head/hairline ratios. Borderline/outlier values abstain.
- Eight approximate shape categories: Oval, Round, Square, Heart, Oblong, Diamond, Triangle (wider jaw), Rectangle. Heart also covers inverted-triangle-like proportions. Hairline shape is not measured.
- Seven apparent skin-depth bands, from Very Fair to Very Deep. L* cutoffs: 82, 75, 66, 55, 46, 32. These revised engineering thresholds are not a calibrated skin-colour scale.
- Local MediaPipe fallback when Haar misses all faces. Existing model is reused; no new package, external photo API or makeup overlay.
- Three illustrative foundation depths per skin-depth/undertone combination (21 combinations). The centre colour plus lighter/deeper comparisons are editorial swatches, not product shade numbers or measured matches. Concealer retains one base-family example. Missing undertone does not invent a foundation match.
- New categories flow through Laravel validation, shade rules, generic illustrations and placement tips. Original photos and existing database results were not overwritten.

## Verification
- Python: 37 tests passed, including seven synthetic depth bands, dark-colour cases, classification boundaries, geometry measurements, missing models, invalid files, and blank/text/noise non-face images.
- Laravel: 39 tests passed, covering uploads, database/display, no-face rejection, service failures, owner access, new response categories and all foundation combinations.
- Live Laravel FaceDetector → HTTP loopback Flask: five images passed after restarting stale service processes. Results include Oval, Diamond, Deep, Very Deep, and zero faces for blank input. No mocked HTTP in this smoke check.
- Batch below: 16 crops from the supplied reference sheets, six existing uploads, and one blank image. Resizing preserved aspect ratio. Existing uploads include duplicates; this is NOT a dataset of 22 independent people.
- Cropped spectrum faces sometimes reach the image edge: shape remains unavailable even when colour is usable.
- No-face Laravel message: “No face detected. Please upload a clear, front-facing photo in good lighting.” The controller test also verifies that no file or database record is saved.

## Important unresolved accuracy limits
The nine face-shape reference crops produced nine Round outputs before the change. Afterward they produce seven Oval, one Diamond and one unclassified result. This removes the observed Round collapse but DOES NOT establish correct classification: several outputs still disagree with the supplied labels. The sheet contains stylized/edited faces and lines, and is not a labelled validation dataset. Do not describe this feature as validated or claim an accuracy percentage. A consented, labelled frontal-photo set is still needed to calibrate and evaluate shapes independently.

The seven skin-spectrum examples also do not all match the illustration labels. The two deepest examples produce Deep and Very Deep, but lighting, rendering and white balance change the lighter categories. A photo measures apparent colour, not someone's intrinsic skin tone, ethnicity, melanin or sun response. The reference's medical/ethnic labels are not model categories.

No new uncertainty numbers are presented as confidence. Covered outlines, pose, makeup and illumination remain limitations. Missing/ambiguous results remain null with a reason. Tests confirm software behavior, not cosmetic or biological ground truth.

## Rechecking in the app
Upload the original photo again to run the revised analysis. Refreshing an older analysis page does not recompute its saved estimates. Foundation presentation updates immediately for saved usable categories. Existing analysis history is retained.

Run Python tests from ai-service: `.venv/Scripts/python.exe -m unittest discover -s tests`.
Run Laravel tests from project root: `php artisan test --compact tests/FaceDetectionTest.php`.
The Laravel milestone tests use an isolated SQLite database and selected dependent migrations because historical migrations duplicate users.role; this check is not a clean full-project migration certification.
