# Makeup infographic
Replaces the retired virtual makeup overlay. HTML/CSS swatches render locally;
no image generation, model download, product image, or face alteration is used.
Existing analysis and saved occasion/style recommendations feed the guide.
MakeupShadeGuide contains editorial illustrative hex colours, not sampled skin
colours or exact brand shades. Foundation families need both depth and undertone.
Missing values have explicit fallback text; generic palettes are not presented as
personalized. No inferred skin type, skin concern, vein colour or season is added.
The actual photo and diagnostic outline are not part of the infographic. Face
landmarks still run for face shape, but no lip, cheek or eyelid overlay geometry
is generated. The retired preview POST route and browser assets are removed.
